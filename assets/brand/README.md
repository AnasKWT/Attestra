# Brand

- `mark.svg`: the Attestra mark, a hexagon with a check, copied from the site's `apps/web/src/app/icon.svg`.
- `mark-<size>.png`: the mark at 32 to 1024 px, transparent background.
- The wordmark is "Attestra" with "ra" in the accent colour.
- Colours come from `apps/web/src/app/globals.css`: accent `#ea580c` on light, `#fb923c` on dark, the brand ramp `#fdba74`, `#f97316`, `#c2410c`.

Regenerate with `tools/make_brand.sh`, then the README images with `tools/.venv/bin/python tools/make_readme_art.py`.
